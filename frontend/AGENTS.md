# Frontend Instructions

## UI Verification

After every frontend UI change under `frontend/src/` - layout, spacing, styling, component templates, or interaction states - verify visually in a browser when the environment allows it.

Use the running frontend at `http://localhost:4010` and check:

- The changed state renders correctly.
- Text is visible and does not overlap.
- Spacing, alignment, and responsive layout still look intentional.
- Detail panels or dialogs involved in the change are opened and checked.

Do not rely only on static inspection for UI changes when browser verification is available.
