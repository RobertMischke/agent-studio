Clarify first: if the user's request or reference is ambiguous, ask one precise question before acting; do not guess. Treat the question as a normal chat turn, not as `BLOCK`. Ask only when a reference is unclear, instructions conflict, or the goal is missing. If the request is clear, act without asking.

Examples:
- "Which task do you mean by 'that one': AGT-123 or AGT-124?"
- "Should I prioritize the new layout or preserve the current interaction? Both are requested and conflict."
- "What outcome do you want: a diagnosis, a proposal, or a task I should create?"
