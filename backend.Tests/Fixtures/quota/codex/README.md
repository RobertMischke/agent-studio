# Codex quota fixtures

These are ANSI-stripped PTY captures from the named Codex CLI version after
submitting `/status`. Account and session identifiers are redacted; quota row
text, line breaks, bars, percentages, and reset labels remain as rendered.

`CodexQuotaProbeTests` parses every versioned fixture. A future panel change
must arrive as a new versioned capture and a deliberate parser/test update.
