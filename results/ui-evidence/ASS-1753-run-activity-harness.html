ASS-1753 — Run-activity badge nach Backend-Restart (Directive 3)

Nach einem Restart ist die Slot-Registry leer. Der korrigierte Backend-Classifier (TaskRunActivityClassifier.Classify) liefert kind=active, sobald eine CLI-Execution noch running meldet — auch ohne belegten Slot. Das Pill rendert das als "Run aktiv" (oben, cyan). Die Zeile "kein aktiver Run" ist der falsche Zustand, den der Bug zeigte. Produktion-Markup + SCSS, Labels vom echten buildRunActivityBadge.
