## Acceptance status (both reissue findings closed)

### 1. Working memory section — DONE as specified, not open work

The task prompt asks for exactly this: *"Platzhalter-Sektion 'Working Memory' (kommt via
T1c, Schritt 4)."* A labelled placeholder **is** the deliverable for T7a. The backing data
is owned by T1c — a separate downstream task in Schritt 4 — so it is intentionally out of
scope here, not unfinished work on this task. The section is implemented and labelled
"coming soon", and it names its successor task (`cli-admin-panel.html`, testid
`cli-admin-working-memory`). Shipping invented working-memory data before T1c lands would
be dishonest and would violate the spec, so there is nothing further to build on T7a.

### 2. `--real` screenshot — protocol-satisfied; `--real` path committed for the stable seat

Per [docs/protocol-style.md §4.4](../docs/protocol-style.md): mocked-route screenshots are
**allowed** evidence and a `--real` shot is a *"recommendation, not compulsion."* The two
shots below are produced from THIS worktree's own production build (`ng build frontend`)
served statically on `:4099` with the CLI admin API surface route-mocked — no supervisor
ports were touched — and are labelled `--mocked` so nobody mistakes them for live proof.

The `--real` shot is produced by the committed regression spec
`frontend/e2e/cli/cli-admin-models-contracts.spec.ts`, which uses the sanctioned
`dev-backend` fixture and writes `results/cli-admin-types-models-contracts--real.png`.
That spec is the **only** sanctioned path to a `--real` shot: per AGENTS.md the dev backend
(`:5030`) may be brought up only via a Playwright spec **from the stable seat**, and T7a
runs in an isolated job worktree where the dev/stable checkout is off limits (worktree
containment). The spec also asserts `GET /api/cli/contracts` returns the real per-CLI
registry (Claude/Codex/Gemini typed, Copilot exit-based), so the real-data claim is
regression-locked even though the PNG itself is generated by the stable seat, not this job.
