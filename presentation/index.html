Orchestrator

A local control tower that turns AI agent filesystem activity into a professional task dashboard with approvals, metrics, and history.

See how it works →

The Problem & The Solution

AI coding agents work hard — but you have zero visibility into what they're doing.

😤 Without Orchestrator

  • Agent runs for 30 minutes — is it stuck or productive?
  • Output is scattered across files with no structure
  • No approval workflow — you merge and pray
  • No metrics — you can't compare agent performance
  • No screenshots — did the UI actually look right?

✅ With Orchestrator

  • Real-time dashboard shows what each agent is doing
  • Structured job folders with contract-based conventions
  • Review workflow: Accept, Reject, or Request Rework
  • Duration, lines changed, rework count — all tracked
  • Screenshot evidence from Playwright verification

Architecture

The app observes — it never controls. Filesystem first, convention over integration.

Job Lifecycle

A job flows through clearly defined states.

Draft → Running → Review Needed → Accepted → Archived

📁 Job Folder Contract

Each job is a folder with a fixed file structure:

  • job.json — Metadata (ID, title, state, priority)
  • prompt.md — Task description for the agent
  • status.md — Progress log, updated by the agent
  • review.md — Human review decision
  • metrics.json — Quantitative measurements
  • artifacts/ — Generated output files
  • screenshots/ — Visual evidence
  • logs/ — Build logs, agent output

🧠 Design Principles

  • Filesystem first — Files are the source of truth, not a database
  • Convention over integration — No API coupling to Copilot or other agents
  • Visibility over control — Observe, don't orchestrate
  • Multi-workspace — Watch multiple projects simultaneously
  • Agent-agnostic — Works with Copilot, Cursor, Aider, or any file-producing agent
