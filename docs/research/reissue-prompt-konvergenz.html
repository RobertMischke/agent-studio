Research: AGT-2380

Do sharper reissue prompts converge faster?

A qualitative corpus review of reissue prompts, combined with the recorded observational comparison and randomized experiment. This HTML edition preserves the delivered research findings and changes their presentation and navigation.

Corpus snapshot: 2026-07-28

Answer

A sharper prompt structure is plausible and operationally useful, but the available data does not establish that it causes faster convergence. The observational comparison slightly favors finding-first prompts, but its confidence interval crosses zero. The strongest actionable evidence is about prompt mechanics: correct diagnosis, a concrete target artifact, linked evidence, explicit non-goals, and a closure criterion reduce avoidable ambiguity. Repeating the same prompt verbatim is a clear nonconvergence signal.

Method

  • Census of 1,375 task cards.
  • 996 reissue files plus 8 no-op recovery files, 1,004 files in total.
  • 440 distinct cards with at least one relevant intervention.
  • Deep qualitative review of 14 representative cards.
  • Comparison with the existing 404-card observational workbench and the predeclared randomized experiment.

Interpretation boundary

The corpus is operational evidence, not a clean causal experiment. Model, task difficulty, infrastructure failures, operator interventions, and changing prompt templates are confounders. End-state completion is also a poor speed metric because almost every card eventually archives.

The template vocabulary is already compact. The remaining opportunity is not another generic builder, but better diagnosis and more precise evidence inside the existing families.

Finding 2: operator steering often adds a second prompt layer

81 of 1,375 human-owned prompt.md files contained appended steering. Within that set, 37 cards repeated the same operator-wave paragraph. Human intervention therefore frequently compensates for an earlier prompt that did not isolate the actual blocker.

Finding 3: evidence links help only after diagnosis is correct

Evidence-rich prompts still loop when they point at the wrong failure class. AGT-2168 received ten steer-diff rounds. Precision is not the number of citations; it is the match between cited evidence and the next executable correction.

Finding 4: raw gate logs are too noisy

AGT-2289 carried about 320 lines of build-gate output, while the first useful error appeared around line 192. A sharper reissue should lead with the first actionable failure and link the full log as supporting evidence.

Finding 5: exact repetition signals nonconvergence

AGT-2255 received five identical evidence-gate reissues. Once the same prompt has failed, sending it again adds no information. The next attempt should change diagnosis, scope, evidence, or escalation state.

Finding 7: the six durable nonconvergers were infrastructure cases

All six cards that did not reach archive ended in the same infrastructure class: review-subject-unmaterialisierbar. Prompt sharpness cannot repair a missing review subject. The system must classify and route this separately.

Finding 8: causal evidence is still incomplete

The randomized experiment is the right mechanism because it holds eligibility and assignment stable. At the checked snapshot it had no completed treatment/control outcomes to interpret, so the observational signal must not be promoted to a causal claim.

Finding 6: eventual completion hides convergence speed

434 of 440 cards, or 98.6%, eventually archived. That makes final completion a nearly constant outcome. More useful indicators are end quote, immediate prompt repetition, attempts, time to stable review subject, and restricted mean survival time.

Pattern catalog for sharper reissue prompts

  1. Diagnosis first. Name the failure class before prescribing work.
  2. Target artifact. Name the file, state transition, result, or evidence item that must change.
  3. Link evidence. Summarize the first actionable signal and link the full log or report.
  4. State the branch basis. Distinguish current diff, prior accepted commits, and infrastructure state.
  5. Define non-goals. Prevent a reissue from restarting the entire task.
  6. Reduce scope. Ask for the smallest correction that can clear the blocker.
  7. Correct the diagnosis. When a prompt fails, change the hypothesis rather than intensifying the same wording.
  8. Never repeat identical text. A prompt hash match should trigger adaptation or escalation.
  9. Give a closure criterion. State the observable condition that permits [[TASK_DONE]].

Recommendations

  1. Do not build a ninth generic reissue-prompt builder.
  2. Extend the existing randomized experiment to build-gate and aspect-block cases.
  3. Use the pattern catalog in the existing template families.
  4. Add an immediate-repetition hash check that forces diagnosis change or escalation.

Top five findings

  1. Eight template families already cover the production reissue surface.
  2. Correct diagnosis matters more than the volume of evidence.
  3. Raw logs should be companions, not the opening of the prompt.
  4. Exact prompt repetition is an actionable loop signal.
  5. The observed benefit is small and uncertain; causal proof remains pending.

Limitations

  • The corpus is a changing production system, not a controlled laboratory sample.
  • Template choice correlates with failure class and task difficulty.
  • Model and thinking-level changes can affect convergence independently of prompt shape.
  • Operator additions are not randomized and may target the hardest cards.
  • Archive is an operational endpoint, not a direct quality measure.
  • Repeated file counts do not by themselves identify distinct semantic attempts.
  • The randomized experiment had no completed outcomes at the checked snapshot.

Three-sentence recommendation

Keep the existing template families, but make every reissue lead with a verified diagnosis, one target artifact, the smallest next action, linked evidence, explicit non-goals, and a closure criterion. Detect identical consecutive prompts and require a changed hypothesis or infrastructure escalation instead of another copy. Continue the predeclared randomized experiment before treating the small observational advantage as a production-wide causal effect.
