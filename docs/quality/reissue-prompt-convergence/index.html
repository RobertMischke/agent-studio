RQ Experiment WorkbenchAGT-2380 · observational snapshot

Research question

Do sharper reissue prompts converge better?

Existing first reissue prompts are classified by a deterministic text rule. Their later explicit pipeline attempts are compared with a right-censor-aware acceptance endpoint.

Decision

No reliable convergence advantage is demonstrated.

Keep the production default unchanged. Test concrete findings-first structure in the controlled arm, without adding generic length, guessed references, or repeated raw logs.

ObservationalTask difficulty, model route, reissue cause, reviewer, and pipeline were not randomized.

The old AGT-2322 conclusion is not an input to this result. This snapshot re-queries the current active and archived task index and applies a narrower first-prompt classifier. It recovered 438 first reissue histories and mapped 404 to explicit attempts; 34 outside the retained timestamp window or without pipeline data were excluded. One API read remained exhausted after two retries and is reported in the snapshot. Records are never reconstructed from the capped previousAttempts list. Route balance is visibly different: the generic group contains 110 Sol tasks and 56 Claude Opus tasks, while finding-first contains 49 Sol and 115 Claude Opus tasks. Task-type balance also differs. These are confounders, not adjustments.

Recommendation

Do not sharpen the production default yet

  1. Keep the current production prompt and the randomized finding-first-v1 promotion gate unchanged.
  2. In the treatment arm, start with numbered open findings and state the observed deficiency before instructions.
  3. For each finding, name a file, symbol, or artifact only when the evidence names it, then state the required change and one focused verification.
  4. Keep raw logs in a separate evidence block and retain scope, permissions, routing, and terminal-sentinel guardrails unchanged.
  5. Do not use extra prompt length, file references, or invented specificity as a proxy for sharpness. Promote only if the controlled experiment meets its predeclared effect, uncertainty, balance, and regression gates.
