# Architecture and quality layer Dossier

This self-contained Dossier is the visual decision surface for
[the umbrella concept](../../concepts/architecture-quality-layer.md). It uses
illustrative contract data, not a live project scan or a real grading result.

Use the four views to review these decisions:

- Project Map is discovered current structure, while the authored Architecture
  Model remains intent.
- Guides use one applicability matcher: Hub consumes project/technology
  matches, while prompt-known adds the explicit task-area selector and reports
  omissions within one aggregate budget.
- Run inventory projects existing durable reports and registered artifacts; it
  is not a new store.
- Grades always carry evidence coverage, rubric version, source revision, and a
  first-class Unknown/stale state.

Source tasks: AGT-2126 (concept), AGT-2127 (Project Graph v1), and AGT-2128
(Style-Guide layer v1).
