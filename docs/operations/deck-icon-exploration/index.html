Effect and recorded decision

A · Project facets Confirmed

An asymmetric project frame contains three visibly different areas and a focus ring. It communicates a console composed of facets while remaining legible at compact rail sizes.

B · Console frame

The strongest console metaphor. Its prompt mark makes it feel operational, but narrows the Deck toward CLI work and under-represents Wiki, settings, and overview panels.

C · Faceted project tile

The most distinctive expression of one multi-sided object. It avoids board grammar completely, but needs the Deck label because its meaning is intentionally abstract.

Round 1: rejected direction

Card stack, layered planes, and board stack

Rejected after Robert's sight review on 28 July 2026. All three motifs interpreted Deck as a card or Kanban-board object. That premise was wrong.

The Deck is the project console containing multiple project facets, including settings, Wiki, token usage, and overview panels. Round 1 remains available as decision history in the original SVG proof, but none of its paths should be implemented.
