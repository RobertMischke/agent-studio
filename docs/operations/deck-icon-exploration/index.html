Deck Icon Exploration

Three small line-icon motifs that separate the project Deck from the current generic board and window symbols. The concepts use the existing 24 by 24 Studio icon grid and inherit currentColor.

Status: ready for Robert's sight review Scope: concept only, no product-code change Proof: light and dark
Recommended

A · Card stack

It says "Deck" most directly, stays distinct from the four-cell grid Board icon, and retains its silhouette at the 10 to 14 pixel sizes used by the Explorer and tab strip.

Mockup row

Effect and recommendation

A · Card stack Recommended

Reads as a deck of cards without reusing the current board grammar. The stepped lower-left silhouette survives compact rendering.

B · Layered planes

The cleanest geometry and a good metaphor for collected project layers. It can also mean infrastructure layers, so it is less specific.

C · Board stack

Keeps a visual link to a board while adding depth. It is the most conservative option, but remains close to today's generic layout icon.
