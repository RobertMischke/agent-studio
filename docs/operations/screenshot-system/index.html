Entschieden (Operator, 09.08.)

Pinned ist die Regel. Die Existing-Data-Regel der Visual Library entfällt; Doku- und Marketing-Shots entstehen aus dem gepinnten Zustand. Demo-Daten dürfen aus realen Daten abgeleitet werden — als bewusster Sanitize-Snapshot in den deterministischen Seed, nicht als Live-Durchgriff. Quellklasse heißt --pinned. Umsetzung: AGT-2530 (Pipeline + Regelwechsel) → WEB-17 (Sync-Fix + Shot-Austausch). Status dieses Dossiers: active/testing bis zur Integration, dann Doku.

02Antwort auf „wohin gehört das?"

Ins Produkt-Repo — wo es schon liegt. Seed, isolierter Stack, Capture-Specs und Runbook leben in agent-taskboard; Konsumenten (Website, Marketing, Deck) beziehen erzeugte PNGs über die Sync-Pipeline bzw. eingecheckte Assets. Es gibt keinen Grund für ein neues Repo oder Tooling — nur für Reparatur, Erweiterung und eine Regel-Entscheidung.

Der eine Regelkonflikt, der zu entscheiden ist

Die Visual Library verbietet synthetische Zustände („existing data only"), die Presentation-Pipeline lebt von ihnen. Für Marketing-/Landing-Shots ist der gepinnte Demo-Workspace klar überlegen: reproduzierbar, aspekt-genau, keine privaten Projektdaten auf der öffentlichen Website. Vorschlag: dritte Quell-Klasse --demo-pinned in Grammatik, Parser und Manifest — ehrlich gekennzeichnet, vom Existing-Data-Pfad getrennt. Die Handoff-Caption „Captured from a working Agent Studio workspace — not a mockup" bleibt wahr: Es ist das laufende Produkt, nur mit gepinnten Demo-Inhalten.

03Was für WEB-16 konkret fehlt

  • Shotliste erweitern: Das Handoff braucht (1) Board-Hero und (2) großes Task-Detail „every signal needed for a decision" — der Demo-Seed muss dafür einen Task mit Evidence, Review-Verdict und Entscheidungszustand enthalten (heute: 12 generische Tasks, ein Grade-File).
  • Annotations-Overlays (max. 3 Labels wie „Bounded task", „Evidence attached", „Human decision") als Teil des Capture-Specs — nicht als nachträgliche Bildbearbeitung.
  • Sync-Bug fixen (Manifest-Pfad) und demo-pinned-Einträge im Sync zulassen.
