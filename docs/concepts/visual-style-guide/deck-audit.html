One Deck. One panel grammar.

The Deck grew section by section. The result is capable but visually fragmented: gray boxes, one-off tints, inconsistent radii, and different header rhythms. This audit puts one screenshot beside every 23 July Deck section and defines Deck-Panel v1 as the convergence baseline for AGT-2280.

§1 · Recommendation

Deck-Panel v1

A quiet container that supports hierarchy without turning every content block into a gray card. The section owns its heading. Panels own bounded content. Tool surfaces can stay full bleed.

Decision ready

Use one tokenized outline panel, flat by default

Deck-Panel v1 uses the card surface, the standard card border, a 10 px radius, spacing-4 inset, and no resting shadow. Muted and attention variants change the entire surface tint. They never add a colored left stripe. Full-bleed tools such as Wiki, Git View, and Prompts keep their workbench layout and apply v1 only to bounded units inside it.

  • Default: calm outline, no elevation.
  • Muted: read-only or secondary content.
  • Attention: acute state only, full tint.
  • Full bleed: no artificial outer panel.
  • Both themes use semantic tokens.

§4 · Delivery contract

What AGT-2280 can implement

The recommendation is a small visual contract, not permission to wrap every Deck surface in another card.

default

Bounded content

Card background, standard border, 10 px radius, spacing-4 inset, no resting shadow.

muted

Secondary content

Muted card background and border for read-only guidance, inherited values, and settled history.

attention

Current acute state

Whole-surface semantic tint and strengthened border. Never a colored left stripe.

full-bleed

Tool workbench

No artificial outer panel for Wiki, Git View, Prompts, and comparable split-pane tools.

.deck-panel {
  padding: var(--studio-spacing-4);
  border: 1px solid var(--studio-card-border);
  border-radius: 10px;
  background: var(--studio-card-bg);
}

.deck-panel--muted {
  border-color: var(--studio-card-muted-border);
  background: var(--studio-card-muted-bg);
}

/* Acute states tint the whole surface. No left status bar. */
.deck-panel--attention {
  border-color: color-mix(in srgb, var(--studio-error) 55%, var(--studio-card-border));
  background: color-mix(in srgb, var(--studio-error) 8%, var(--studio-card-bg));
}
