Selection rule

  • Choose A for a small list whose context already explains what is absent.
  • Choose B for a neutral panel state with no local recovery action.
  • Choose C only when the action is available, safe, and owned by this surface.
  • Check wording with AGT-2237. Empty-state copy is guidance, not decoration.
  • Do not use a warning color merely because content is absent.
