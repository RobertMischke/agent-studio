Ownership boundaries

The scaffold is deliberately small and machine-portable.

G
Git owns contentDocs, prompt files, history, and branch provenance.
W
Wiki owns presentationTree, rendering, search, metadata, and explicit editing.
A
Application owns tasksLifecycle records linked to repository, base branch, revision, and task branch.
L
Registry owns local stateAbsolute paths, refresh timestamps, checkout status, and credentials.
