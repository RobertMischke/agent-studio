Existing path · persistence required

Task execution lease

Held by the runner/session holder. Protects exactly-one execution and every outcome-affecting write.

  • Long enough for heartbeat safety
  • Monotonic execution fencing token
  • Loss stops and reaps the stale generation
New interaction contract

Control lease

Held by one authenticated UI attachment. Protects stdin, steer, approve, cancel, and resume commands.

  • Short TTL and explicit owner
  • Monotonic control fencing token
  • Loss makes the client read-only, not the session terminal

A UI may lose control. It must never lose the session's execution lease on the holder's behalf.
