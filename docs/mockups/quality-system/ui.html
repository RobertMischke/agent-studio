Security overview audit

Re-checks the project's security overview against the current code. Holistic, manual.

ARCH-DRIFT Audit

Architecture drift

Compares current architecture against ADRs. Flags decisions that have silently eroded.

project architecture severity: warn
TRACEABILITY-COVERAGE Audit

Traceability coverage

Verifies that errors and slow ops are instrumented across the whole codebase.

project traceability severity: warn
CODE-CHECK Task Check

Code review on diff

Reviews the diff this task produced. Flags style, naming, dead code, missing tests.

task code-quality severity: warn
TRACEABILITY-DIFF Task Check

Traceability on diff

Checks the diff adds error-handling and timing where it touches new paths.

task traceability severity: warn
TEST-COVERAGE-DELTA Task Check

Test coverage delta

Warns if new code paths land without test coverage.

task code-quality severity: info
SEC-DIFF Task Check

Security check on diff

Lightweight pattern check on changed files (input validation, secret leakage, eval).

task security severity: high
STARTUP-LATENCY Probe

App startup latency

Cold-starts the frontend, measures time-to-interactive. Compared against threshold.

runtime performance severity: warn
BOARD-POLL-ROUNDTRIP Probe

Grouped-jobs poll roundtrip

Times the polled endpoint from inside the running app over 200 jobs. Threshold 1s.

runtime performance severity: warn
