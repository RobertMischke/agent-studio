What changes per scenario

  • Low autonomy (level 0..1): NeedsClar lane is visible; orchestrator-prep iterates at most once; queue may run thin.
  • Balanced (level 2, default): borderline tasks accepted; only genuinely-unclear bounce.
  • Confident (level 3): bounce only when invent-major-scope; iteration-cap drops to advisory.
  • Fully auto (level 4): NeedsClar lane hidden; orchestrator never bounces; iteration-cap exit logs a [supervisor] chat-note.

Lane visibility

  • 1a-orchestrator-prep always visible (rail when autonomy = 0).
  • 1b-needs-human-review hide-when-empty AND hide-when-autonomy=4.
  • 5-human-review hide-when-empty (existing rule).
  • Optional failed-pickup hide-when-empty (existing rule).
